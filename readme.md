# Sign-up Form

A responsive sign-up form built as part of **The Odin Project** JavaScript curriculum.

## Features

- Split-screen layout built with CSS Flexbox
- HTML5 client-side validation (`required`, `minlength`, `:user-valid`, `:user-invalid`)
- Basic JavaScript password-matching verification on submit

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
